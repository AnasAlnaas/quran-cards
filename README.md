# بطاقات القرآن — Quran Cards

A group card game for Quran memorisation circles and classrooms. The teacher puts it on a screen and up to six players take turns opening cards. Same engine as Akhlaq Cards (rescue the question, held answers, review round).

## Riwaya and sections
- **Riwaya** is chosen on the main screen: **Qalun** (رواية قالون عن نافع, the default on every visit) or **Hafs** (رواية حفص عن عاصم). Ayah text, ayah numbering and ayah counts all follow the chosen riwaya. Ayah counts differ in 20 of the 69 surahs from al-Ahqaf to an-Nas, and juz boundaries can fall on different ayah numbers.
- **Sections are memorisation ranges (juz)**, multi-select: juz 25–30 are live. Juz 1–24 are listed as "قريباً". Juz is tracked per ayah: juz 25 starts inside Fussilat (Qalun 41:46 = Hafs 41:47) and juz 27 inside adh-Dhariyat (51:31).

## Question types
Memorisation cards make up about three in every four (`MEMO_RUN` in `game.js`). They are generated from the mushaf text, separately for each riwaya:
| Kind | Question | Level |
|---|---|---|
| `begin` | بمَ تبدأ سورة…؟ (opening ayat; enough ayat to tell it apart, e.g. the Ha-Mim surahs) | easy |
| `after` | ما الآية التي بعد قوله تعالى…؟ | medium |
| `sura` | في أيّ سورة هذه الآية؟ | easy (first ayah) / medium |
| `end` | أيّ سورة تُختم بهذه الآية؟ | medium |
| `words` | ما الكلمات التالية؟ (start of an ayah; options are real 2–3-word runs) — not in juz 30 | medium |
| `fill` | أكمل الآية (last word hidden; options are real end-words) — not in juz 30 | medium |
| `prev` | ما الآية التي قبل قوله تعالى…؟ | hard |
| `similar` | في أيّ سورة جاءت الآية بهذا اللفظ؟ (an ayah with a near-twin in another surah; the twin's surah is one of the options) | hard |

Knowledge cards, about one in four until they run out:
| Kind | Question |
|---|---|
| `next` | ما السورة التي تلي سورة…؟ |
| `count` | كم عدد آيات سورة… في رواية…؟ |
| `who` `story` `meaning` `virtue` | hand-written in `cards.js` (juz 29–30 so far; virtues carry a hadith grading badge) |

## Quran text — rules
- Every ayah comes from the **King Fahd Glorious Quran Printing Complex** data (KFGQPC Qaloon v10, Hafs v18), via the [thetruetruth/quran-data-kfgqpc](https://github.com/thetruetruth/quran-data-kfgqpc) mirror of the [complex's developer releases](https://qurancomplex.gov.sa/en/techquran/dev/). Each riwaya is shown in its own KFGQPC font (`fonts/`).
- **No Quran text is typed by hand.** Hand-written cards point to an ayah with `{{surah|search words}}`. The game finds those words in the chosen riwaya and inserts the exact mushaf text, then shows the full ayah and reference after the answer.
- Wrong options are never invented ayat: they are other real ayat, real end-words, surah names, people or meanings.
- Duplicate ayat (same text in more than one place) are never asked about by position.

## Files
- `mushaf.js` — generated by `node tools/build-mushaf.js` from `_source/` (the full KFGQPC JSON files, git-ignored). Juz 25–30 (all of Fussilat onward), about 580 KB (Netlify serves it compressed).
- `gen.js` — builds the cards (browser and node).
- `cards.js` — hand-written cards (`HAND`).
- `game.js` — game engine. `index.html` — page and styles.
- `tools/check.js` — run after any change: checks every `{{…}}` key resolves to exactly one ayah in **both** riwayat, that options are distinct, and that every generated ayah is verbatim in the mushaf data.

## Adding a juz
1. Lower `FIRST_SURA` in `tools/build-mushaf.js` (or change the filter to juz), run it.
2. Add the juz to `JUZ_READY` in `game.js`.
3. Add hand-written cards for it to `cards.js`, run `node tools/check.js`.
4. Bump `CACHE` in `sw.js`.
